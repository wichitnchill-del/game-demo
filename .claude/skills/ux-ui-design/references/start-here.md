# เริ่มใช้สกิล (Start here)

Show this to the user when the request is vague or they ask how to use the skill.
Keep it short; reply in the user's language.

## 1. บอก 4 อย่างนี้ (ยิ่งครบ ยิ่งตรง)

```
ทำอะไร:    landing page / แอดมิน / แอปมือถือ / ฟอร์ม / ตรวจ UI
ใช้บน:    เว็บบนคอม / เว็บมือถือ / แอป / LINE
ให้ใคร:    เช่น พนักงานร้านอาหาร ใช้แท็บเล็ต
ต้องมี:    เมนู/หน้า/ปุ่มที่ต้องมี
ชอบแบบ:   เว็บตัวอย่าง, สีแบรนด์, โลโก้ (ถ้ามี)
```

## 2. ตัวอย่างคำสั่ง

| อยากได้ | พิมพ์ |
| --- | --- |
| Landing page | `ทำ landing page คาเฟ่ ลูกค้าวัยทำงาน ต้องมีเมนู แผนที่ ปุ่มจอง โทนอบอุ่น` |
| แอดมิน | `ออกแบบหน้าแอดมินร้านคลินิก มีนัดหมาย คิว คนไข้ ใบเสร็จ ใช้บนคอม` |
| เมนู | `ทำ sidebar ร้านอาหาร 3 บทบาท: เสิร์ฟ ครัว ผู้จัดการ` |
| ฟอร์ม | `ฟอร์มสมัครสมาชิก ชื่อ เบอร์ อีเมล มี loading ตอนกดส่ง` |
| ตรวจ UI | `ตรวจ UI ทั้งหมดว่าเหมาะกับการใช้งานไหม <URL หรือโฟลเดอร์>` |
| ธีม | `เลือกธีม daisyUI ให้แอปจองคิวทำเล็บ` |
| แอป / LINE | `ทำหน้าจองคิวร้านทำเล็บใน LINE จ่ายมัดจำ PromptPay` |
| ล็อกอิน | `หน้าเข้าสู่ระบบด้วยเบอร์โทร + OTP และ LINE` |
| ประเมินเว็บ | `ประเมินเว็บไซต์ <URL> ต้องปรับปรุงอะไร` |
| วางแผน | `วางแผนฟีเจอร์แอปร้านกาแฟ ทำ MVP ใน 1 เดือน` |
| เนื้อหา | `เขียนคำอธิบายเว็บ + about us ร้านคลินิกฟัน` |
| ใบเสร็จ | `ใบกำกับภาษีเต็มรูป A4 + สลิป 80 mm + ส่งทาง LINE` |
| PDF | `ทำใบเสนอราคาเป็น PDF ภาษาไทย A4 มีเลขหน้า ส่งอีเมลได้` |
| ตั้งค่า | `หน้าตั้งค่าบัญชี มีลบบัญชี + แบนเนอร์คุกกี้ PDPA` |
| หน้าว่าง / error | `ทำหน้า 404, 500, ไม่มีเน็ต, ยังไม่มีข้อมูล ให้แอปเรา` |
| อัลตร้า | `อัลตร้า: ออกแบบแอปสั่งอาหารร้านเรา` (3 แบบให้เลือก ตรวจครบทุกจอ) |

## 3. ขั้นตอนที่สกิลจะทำ

1. ถามสั้น ๆ ถ้าข้อมูลไม่พอ (ไม่เกิน 3 ข้อ)
2. ส่ง **wireframe แบบร่าง** ให้ดูก่อน (ตัวอย่างด้านล่าง)
3. คุณเลือก / แก้
4. ทำงานจริง: HTML (Tailwind + daisyUI) หรือ Figma
5. เช็ค checklist แล้วส่ง พร้อมบอกสิ่งที่ยังไม่ได้ตรวจ

## 5. เคล็ดลับ
- ส่งรูปหน้าจอ หรือ URL เว็บที่ชอบ → ได้ตรงใจกว่า
- บอกว่าใช้บนมือถือหรือคอม
- ไม่ชอบตรงไหน บอกเป็นจุด: "เมนูตกบรรทัด", "สีจืด", "ปุ่มเล็ก"
