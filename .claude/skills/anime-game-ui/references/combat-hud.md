# Combat HUD Spec & Layout

คู่มือการวางเลย์เอาต์หน้าจอต่อสู้สำหรับเกมแอ็กชัน RPG เรียลไทม์ในจักรวาลอนิเมะ (โปรเจกต์นี้ไม่มีระบบเทิร์น)

---

## 1. องค์ประกอบสำคัญ 5 จุดบนหน้าจอต่อสู้

```text
[ 1. Combo Counter (ขวากลาง) ] ──────────────────────────── [ Top Right: Status / Pause ]
• จำนวนฮิต + ระดับคอมโบ                                       • Wave Counter (1/3)
• แถบเวลาด้ายขาด (1.2 วินาที)                                   • Pause / Menu

[ 2. Target Info ] ────────────────────────────────────────
• ชื่อศัตรู & ระดับเกรดตรา
• หลอด HP บอส + เกจ Seal Burst (印弾き) ที่ศัตรูสะสมระหว่างโดนคอมโบ
• ไอคอนธาตุที่แพ้ทาง (ดิน > ลม > น้ำ > ไฟ > ดิน)
• ดีบัฟที่ติดอยู่ พร้อมวงนับเวลาถอยหลังเป็นวินาที

                       [ พื้นที่ฉากต่อสู้ 3D / 2D Action ]
                       • ตัวละครผู้เล่นยืนฝั่งซ้าย/หลัง
                       • ศัตรูยืนฝั่งขวา/หน้า
                       • Floating Combat Text & Particle VFX

[ 3. Party Status Dock ] ──────────────── [ 4. Skill Deck ]
• การ์ดตัวละคร 3-4 คน                      • ปุ่ม L / H / J / D (ตีเบา ตีหนัก กระโดด พุ่ง)
• หลอด HP (เขียว/แดง)                      • Active Skills (ตามจำนวน slot 2-6)
• หลอดลมหายใจเวท (ฟ้า/ส้มเมื่อเหลือน้อย)       • ท่าไม้ตาย / Burst / ร่างปลดปล่อย
• สถานะตราแกน (ปกติ / ร้าว / แตก)          • ปล่อยเวทดูด (กรณีของน็อลล์)
• ทรัพยากรเฉพาะตัวละคร (โคลเวอร์ / เคาน์เตอร์)  • ไอเท็ม / เมนูหนี
```

## 2. รายละเอียดแต่ละ Component

### A. Combo Counter — Endless Thread (無限連撃)
- **การจัดวาง:** ขวากลางจอ ไม่บังจุดปะทะ
- **ตัวเลขฮิต:** ฟอนต์หนาเอียง เด้งขยาย 1.2x ทุกฮิตแล้วหดกลับ (0.08s)
- **แถบด้าย:** เส้นด้ายใต้ตัวเลข หดจากขวาไปซ้ายใน 1.2 วินาที เต็มใหม่ทุกครั้งที่ตีโดน เหลือน้อยกว่า 0.3s เปลี่ยนเป็นสีแดงและสั่น
- **ระดับคอมโบ:** เปลี่ยนป้ายและสีตามจำนวนฮิต 20 / 50 / 100 / 200 / 500 (Threaded 糸通 → Woven 織成 → Unbroken 不断 → Thread of Fate 運命の糸 → Limitless 無限) ตัวเลขเรืองแสงสีธาตุของตัวละคร
- **ท่าซ้ำ:** ใช้ท่าเดิมครั้งที่ 2 และ 3 ไอคอนท่าเล็กๆ ใต้ตัวเลขจะขึ้นกรอบเหลืองแล้วแดง เตือนก่อนศัตรูหลุด
- **ด้ายขาด:** เส้นด้ายขาดกลางพร้อมเสียง "ปึ๊ง" ตัวเลขร่วงลงแล้วจางหาย แสดงยอดฮิตสูงสุด 1.5 วินาที

### A2. เกจ Seal Burst ของศัตรู
- อยู่ใต้หลอด HP ศัตรู สีม่วง เติมขึ้นทุกฮิต
- ใกล้เต็ม (80%+) ตราบนตัวศัตรูกะพริบ เป็นสัญญาณให้ผู้เล่นเตรียมสวนหลบ
- สวนหลบสำเร็จ: เกจแตกเป็นเศษแสง รีเซ็ตเป็น 0 เวลาช้าลง 0.5s

### B. หลอดลมหายใจเวท & สถานะความเหนื่อยล้า
- **ค่าปกติ (31% – 100%):** หลอดสีฟ้าไอเทล (Cyan/Aqua) เปล่งแสงนวล
- **ค่าเตือนภัย (1% – 30%):** หลอดเปลี่ยนเป็นสีส้มแอมเบอร์ กระพริบช้าๆ เป็นจังหวะชีพจร
- **สถานะหมดลมหายใจ (0% - สับสน / Confusion):**
  - หลอดกลายเป็นสีม่วงดำพร้อมไอคอนหมอกควัน
  - มีเครื่องหมายคำถามหรือสัญลักษณ์หมุนวนเหนือหัวตัวละคร
  - ช่วงที่สับสน (ไม่กี่วินาที) ตัวละครมีโอกาสโจมตีพวกเดียวกันเองตามกฎของโลกปี 2026

### C. มาตรวัดสถานะตราแกน (Core Seal Integrity)
ตราแกนคือหัวใจของเกมนี้ตาม `game-design.md`:
1. **สถานะปกติ (Intact):** ตราส่องสว่างตามสีสาย (สายเสริม = ขาวเงิน, สายแปร = ประกายสีธาตุ)
2. **สถานะร้าว (Cracked):**
   - มีรอยแตกสีแดงเลือดพาดผ่านตรา
   - ขอบหน้าจอมีเอฟเฟกต์ Vignette สีแดงจางๆ
   - ได้รับบัฟ EXP พิเศษ (เล่นเสี่ยงเพื่อเลเวลอัป) แต่เสี่ยงต่อการถูกปลดออกจากการต่อสู้
3. **สถานะแตก (Shattered):**
   - ตราแตกกระจายเป็นเศษละออง
   - ตัวละครทรุดลงพื้น ไม่สามารถสั่งการได้
   - ตัวเลือกเดียวคือต้องให้เรนใช้ "เข็มเย็บตรา" (ซึ่งมีราคาที่ต้องจ่ายถาวรในเนื้อเรื่อง)

## 3. รูปแบบการควบคุม (Input Adaptability)

| แอ็กชัน | แป้นพิมพ์ + เมาส์ (PC) | คอนโทรลเลอร์ (Gamepad) | หน้าจอสัมผัส (Mobile) |
|---|---|---|---|
| L ตีเบา | คลิกซ้าย / J | ปุ่ม X / Square | แตะปุ่มโจมตีใหญ่ขวาล่าง |
| H ตีหนัก (กดค้าง = ตีเสย) | คลิกขวา / K | ปุ่ม Y / Triangle | แตะปุ่มหนัก / กดค้าง |
| J กระโดด (กดสองครั้ง = สองชั้น) | Spacebar | ปุ่ม A / Cross | ปัดขึ้นบนจอฝั่งขวา |
| D พุ่ง / สวนหลบ | Shift | ปุ่ม B / Circle | ปัดไปทางที่ต้องการ |
| S สกิล 1–3 | 1 / 2 / 3 | R1 + X / Y / B | แตะไอคอนสกิล |
| S+H ไม้ตาย | 1+คลิกขวา / Q | R1 + R2 | ปุ่มไม้ตายเรืองแสงเมื่อเกจเต็ม |
| ล็อกเป้า | Tab / คลิกกลาง | R3 | แตะที่ตัวศัตรูโดยตรง |
