# ออกแบบท่าเต้น

ใช้คู่กับสกิล `manga-writer` (สำหรับฉากในเรื่อง) และ `simple-words` (ภาษาที่ใช้อธิบาย)
ข้อมูลเพลงของเรื่องอยู่ในโฟลเดอร์ `songs/` ถ้าเป็นเพลงของลูมิ ให้อ่าน `songs/lumi-theme.md` ก่อน

## แนวทางที่ 1: คิดท่าใหม่จากเพลง

### ขั้นที่ 1 เก็บข้อมูลเพลงก่อน (ถ้าไม่มี ให้ถาม)
- ความเร็ว (BPM) และจังหวะ 4/4 หรืออื่น
- โครงเพลง: Intro / Verse / Pre-Chorus / Chorus / Rap / Bridge / Outro พร้อมความยาวแต่ละท่อน (นับเป็นชุด 8 จังหวะ)
- อารมณ์ของแต่ละท่อน: สดใส / หนักแน่น / พลิ้ว / เศร้า
- ใครเต้น กี่คน เต้นบนเวที ในห้อง หรือกลางถนน
- ใช้ทำอะไร: อนิเมชัน เกม MV หรือคนเต้นจริง

### ขั้นที่ 2 เขียนท่าเป็นตาราง 8 จังหวะ
แยกทุกท่าเป็น 4 ส่วน: **เท้า · แขน · ลำตัว/หัว · ทิศทาง/ระดับ (สูง กลาง ต่ำ)**

```text
ท่อน: Chorus (ชุดที่ 1/4)
| จังหวะ | เท้า | แขน | ลำตัว/หัว | ทิศ/ระดับ |
|---|---|---|---|---|
| 1 | ก้าวขวาออกข้าง | ชูนิ้วชี้ขวาขึ้นฟ้า | เอียงหัวซ้าย | หน้า · กลาง |
| 2 | ชิดเท้า | ชูสองนิ้วซ้าย | ... | ... |
| ... | | | | |
| 8 | | | | |
```

### ขั้นที่ 3 กฎการคิดท่า
- **ท่าฮุคต้องทำตามได้ด้วยมือข้างเดียวขณะยืนอยู่กับที่** แฟนในคอนเสิร์ตหรือคนดูต้องเลียนได้
- ท่าฮุคยาวไม่เกิน 8 จังหวะ และใช้ซ้ำทุกคอรัส
- Verse ใช้ท่าเล็ก Chorus ใช้ท่าใหญ่ Bridge ลดลงเหลือท่านิ่งหรือเคลื่อนช้า
- ท่าต้องบอกเรื่องหรือนิสัย ไม่ใช่สวยอย่างเดียว (เช่น ท่านับ 1-2-3 ล้อกับเรน)
- ระวังท่าที่ทำให้ตัวละครดูเกินอายุ ตัวละครส่วนใหญ่อายุ 15 และเรต 13+
- ทำเครื่องหมาย **[sakuga]** ตรงท่าที่ควรวาดละเอียดเป็นพิเศษในอนิเมชัน

### ขั้นที่ 4 สตอรีบอร์ดท่าเต้น
ทำเป็นเฟรมๆ ก่อนส่งไปทำวิดีโอ ใช้รูปแบบเดียวกับ storyboard ในสกิล `manga-writer`:

```text
เฟรม 1 [จังหวะ 1–2 ของ Chorus] [มุมกล้อง: medium, หน้าตรง]
  ท่า: ...
  แสง/ไฟเวที: ...
  เอฟเฟกต์เวท: ...
```

## แนวทางที่ 2: ใช้เครื่องมือ AI ทำวิดีโอเต้น

### สร้างท่าจากเพลง/คำสั่ง
- เครื่องมือสายนี้ เช่น mvntSTUDIO หรือเวิร์กโฟลว์ทำสตอรีบอร์ดเป็นเฟรมก่อนแล้วค่อยสร้างวิดีโอ (เช่น Seedance)
- พรอมต์ต้องมี: แนวเพลง · BPM · ท่อนเพลง · อารมณ์ · จำนวนคน · สถานที่ · มุมกล้อง · ท่าหลักที่ต้องมี
- ตัวอย่างพรอมต์:
  ```text
  Anime idol girl dancing on a concert stage, J-pop, 150 BPM, chorus section,
  bright and cute mood, signature move: index finger up on beat 1, two fingers on beat 2,
  star shape with both hands above head on "LUMI!", gold stage lights, medium shot, front view
  ```

### Motion transfer (เอาท่าจากวิดีโอจริงไปใส่ตัวละคร)
- ใช้คลิปอ้างอิงที่ **ถ่ายเองหรือมีสิทธิ์ใช้** เท่านั้น ห้ามใช้ท่าเต้นของศิลปินจริงไปลอกทั้งชุด
- ถ่ายคลิปอ้างอิง: กล้องนิ่ง เห็นทั้งตัว พื้นหลังเรียบ แสงพอ ใส่เสื้อผ้าไม่หลวมเกิน (ให้ AI เห็นข้อต่อ)
- เครื่องมือสายนี้ เช่น Kling AI หรือเครื่องมือ pose estimation / motion transfer อื่นๆ
- ระบุในพรอมต์ว่าจะเปลี่ยนอะไร: ตัวละคร · มุมกล้อง · ความเร็ว · ฉาก

### สำหรับเกม (ระยะยาว)
- เก็บคลิปท่าเต้นที่ออกแบบเอง แปลงเป็นข้อมูลโครงกระดูก (pose/skeleton) หรือ motion capture
- ใช้กับตัวละคร 3D ในเกม หรือใช้เทรนโมเดลสร้างการเคลื่อนไหวต่อ
- ตั้งชื่อไฟล์ท่าตามเพลงและท่อน เช่น `lumi_light_chorus_A.bvh`
