# คำศัพท์อนิเมะ — ใช้คุยงานและวางแนวเรื่อง

## 1. แนวเรื่องและเซตติ้ง
| คำ | ความหมายสั้นๆ | ใช้กับเรื่องเรายังไง |
|---|---|---|
| Isekai (ต่างโลก) | ตัวเอกหลุดไปหรือไปเกิดใหม่ในโลกอื่น | ไม่ใช่แนวเรา (โลกเราคือเมืองจริงปี 2026) |
| Slice of Life | ชีวิตประจำวัน ไม่มีปมใหญ่ | ใช้กับตอนพักระหว่างอาร์ค เช่น ทีม 5 คนกินข้าวด้วยกัน |
| Iyashikei (ฮีลใจ) | สงบ ผ่อนคลาย เยียวยาคนดู | ฉากครัวของโอลี่กับป้าเพียง |
| Mecha | หุ่นยนต์ยักษ์ | ไม่ใช่แนวเรา |
| Mahou Shoujo | สาวน้อยเวทมนตร์ แปลงร่างสู้ | ไม่ใช่แนวหลัก ใช้ล้อเลียนในมุกได้ |

แนวของเราคือ **Urban Fantasy · Magic School · RPG System · Psychological**

## 2. ประเภทตัวละคร (Dere Types และ Tropes)
| คำ | ความหมาย | ตัวละครที่ใกล้เคียง |
|---|---|---|
| Tsundere | ปากร้าย ใจห่วง | **เซ็ตสึ** (ขี้โมโหแต่ห่วงเรน), **มิโอ** บางส่วน |
| Kuudere | หน้านิ่ง เย็นชา แต่ข้างในอ่อนโยน | **ฮารุ** (หน้านิ่งเพราะกลัวอารมณ์ไหลเป็นน้ำ) |
| Dandere | ขี้อาย พูดน้อย สนิทแล้วสดใส | น้องสาวน็อลล์ *(เสนอ)* |
| Yandere | คลั่งรักจนพร้อมทำร้าย | ระวังใช้ ถ้าจะใช้ ควรเป็นตัวร้ายรอง |
| Chūnibyō | เพ้อว่าตัวเองพิเศษ มีพลังลับ | ใช้กลับด้านได้: ในโลกนี้บางทีมันจริง (กฎ "ความเชื่อสร้างธาตุ") |

> ใช้ trope เป็นจุดเริ่ม ไม่ใช่จุดจบ ตัวละครทุกตัวต้องมี **เหตุผลในโลกนี้** ว่าทำไมนิสัยเป็นแบบนั้น (เช่น ฮารุเป็น kuudere เพราะราคาของธาตุน้ำ)

## 3. ศัพท์การผลิต
| คำ | ความหมาย |
|---|---|
| Cour (คูร์) | 1 ซีซัน = 3 เดือน ประมาณ 11–13 ตอน |
| OVA | ตอนพิเศษลงแผ่นหรือสตรีมตรง ไม่ฉายทีวี |
| ONA | อนิเมะที่ทำมาลงอินเทอร์เน็ตเป็นหลัก |
| Seiyuu (เซยู) | นักพากย์ญี่ปุ่น |
| Sakuga (ซากุกะ) | ฉากที่ภาพเคลื่อนไหวสวยเด่นกว่าปกติ |
| Filler | ตอนที่แต่งเพิ่ม ไม่มีในต้นฉบับ |

**ใช้วางแผน:** เรื่องเราแบ่งเป็น **เฟส** ไม่ใช่ซีซัน (1 เฟส ≈ 1 อาร์ค ถ้าทำเป็นอนิเมะ 1 เฟสอาจยาวประมาณ 1 cour) · ฉากที่ควรเป็น sakuga ให้ทำเครื่องหมายไว้ใน storyboard เช่น เรนเสริมทั้งห้อง หรือภูตตื่นครั้งแรก

## 4. วัฒนธรรมแฟนคลับ
| คำ | ความหมาย |
|---|---|
| Waifu / Husbando | ตัวละครหญิง/ชายที่แฟนรักเป็นพิเศษ |
| Canon / Non-Canon | เนื้อเรื่องทางการ / เนื้อหาเสริมที่ไม่นับ |
| Ship / Shipping | จับคู่ตัวละคร (คู่จริงหรือคู่จิ้น) |
| Spoiler | เปิดเผยจุดหักมุมล่วงหน้า |

**ใช้กับงานเรา:**
- เขียนให้ไบเบิลเป็น **canon** เสมอ ไอเดียที่ยังไม่ยืนยันให้ติดป้าย *(ชั่วคราว)* หรือ *(เสนอ)*
- คู่ canon ตอนนี้: **โอลี่ × ฮารุ** ส่วนคู่ที่แฟนน่าจะ ship เอง: เรน × น็อลล์ (มิตรภาพที่ผูกด้วยแม่)
- เวลาทำตัวอย่างหรือโปรโมต ห้ามเปิดปมในส่วนที่ 9 ของไบเบิล (spoiler)
