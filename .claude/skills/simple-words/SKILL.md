# เขียนให้ง่าย

เป้าหมาย: คนอ่านเข้าใจได้ในรอบเดียว ไม่ต้องหยุดคิดว่าคำนี้แปลว่าอะไร

## กฎหลัก 7 ข้อ

1. **ประโยคสั้น** — ประโยคเดียวพูดเรื่องเดียว ถ้ามีคำว่า "ซึ่ง" "โดยที่" "อันเป็น" ซ้อนกันเกินหนึ่งครั้ง ให้แยกเป็นสองประโยค
2. **คำธรรมดาก่อนคำหรู** — ใช้คำที่พูดกันจริงในชีวิตประจำวัน
3. **ศัพท์อังกฤษ/ญี่ปุ่นต้องมีคำไทยกำกับครั้งแรก** — เช่น "ซากุกะ (ฉากที่ภาพเคลื่อนไหวสวยเป็นพิเศษ)" ครั้งต่อไปใช้คำเดียวได้
4. **ศัพท์เฉพาะในโลกเรื่องใช้ให้ตรงกันทุกที่** — เช่น ใช้ "ตราแกน" ไม่สลับเป็น "ตราเวท" หรือ "แกนเวท"
5. **กริยานำ ไม่ใช่คำนามนำ** — "เขาตัดสินใจ" ดีกว่า "เขาทำการตัดสินใจ" / "ตรวจ" ดีกว่า "ดำเนินการตรวจสอบ"
6. **บอกตรงๆ ก่อน ค่อยขยาย** — ประโยคแรกของย่อหน้าต้องบอกใจความ
7. **อ่านออกเสียงได้** — ถ้าอ่านแล้วสะดุดหรือต้องหายใจกลางประโยค ให้ตัดหรือแก้

## ห้ามใช้: คำที่ฟังเหมือน AI เขียน

คำพวกนี้ไม่ผิด แต่คนจริงไม่ค่อยพูด พอใช้บ่อยจะอ่านแล้วรู้ทันทีว่าเครื่องเขียน **ห้ามใช้เลย** ยกเว้นตัวละครคนนั้นพูดแบบนี้จริงๆ (เช่น เจ้าหน้าที่กรมฯ ที่พูดแบบแถลงข่าว)

| คำ/สำนวนแบบ AI | ใช้แทน |
|---|---|
| นอกจากนี้ / ทั้งนี้ / อีกทั้ง | แล้วก็ / อีกอย่าง / (ขึ้นประโยคใหม่เฉยๆ) |
| อย่างไรก็ตาม | แต่ |
| ถือเป็น / นับว่าเป็น | คือ / เป็น |
| ไม่ใช่แค่… แต่ยัง… | (พูดทีละเรื่อง) |
| ไม่ว่าจะเป็น… หรือ… | (ยกตัวอย่างตรงๆ) |
| ในยุคปัจจุบัน / ในโลกที่… | (ตัดทิ้ง) |
| การเดินทาง / เส้นทาง (ในความหมายชีวิต) | เรื่อง / ช่วงที่… |
| ก้าวสำคัญ / จุดเปลี่ยนสำคัญ | ครั้งแรกที่… / ตอนที่… |
| ทรงพลัง / ลึกซึ้ง / งดงาม (ชมลอยๆ) | บอกว่าดีตรงไหนแทน |
| ยกระดับ / ขับเคลื่อน / ปลดล็อก / โอบรับ | ทำให้ดีขึ้น / ทำให้… / เปิด / ยอมรับ |
| สะท้อนให้เห็นถึง | บอกว่า… / แปลว่า… |
| เปรียบเสมือน / ราวกับว่า (ใช้ถี่) | เหมือน (และใช้แค่ตอนจำเป็น) |
| ห้วงเวลา / ท่ามกลาง / แห่ง… (ใส่เพื่อให้ดูหรู) | ตอน / ระหว่าง / ของ |
| จิตวิญญาณ / บทเรียนล้ำค่า / ความหมายที่แท้จริง | (ตัด หรือบอกสิ่งที่ตัวละครเรียนรู้ตรงๆ) |
| ทุกสิ่งทุกอย่าง | ทุกอย่าง |
| สรุปแล้ว / กล่าวโดยสรุป | (ไม่ต้องเกริ่น พูดข้อสรุปเลย) |

**ห้ามโครงแบบ AI ด้วย:**
- ปิดท้ายย่อหน้าด้วยประโยคคมๆ ที่สรุปความหมายซ้ำทุกครั้ง
- ลิสต์สามอย่างติดกันเพื่อให้ฟังดูครบ ("อบอุ่น ลึกซึ้ง และทรงพลัง")
- เปิดด้วยการชมคำถาม ("คำถามที่ดีมาก!")
- ใช้ขีดยาว — เชื่อมประโยคบ่อยๆ
- คำบรรยายอารมณ์สำเร็จรูป ("หัวใจเต้นแรง" "ลมหายใจสะดุด" "น้ำตาไหลอาบแก้ม") ให้ **เขียนสิ่งที่ตัวละครทำ** แทน เช่น โอลี่ลบข้อความทิ้ง

## บทพูดตัวละคร

- คนจริงไม่พูดเป็นประโยคสมบูรณ์ ตัดประธานได้ ใช้คำลงท้ายตามนิสัย (ครับ/ค่ะ/วะ/ว่ะ/จ้ะ/นะ)
- **เด็กพูดเหมือนเด็ก** — ตัวละครอายุ 12–15 ใช้คำสั้น ใช้คำซ้ำ (เช่น "ไม่รู้ ไม่รู้")
- **ห้ามให้ตัวละครพูดเหมือนบรรยาย** เช่น ✗ "ข้าคือผู้ครองธาตุดินซึ่งมีความแข็งแกร่ง" → ✓ "ดินข้าแข็งสุดในห้องแล้ว"
- คำศัพท์ของโลก (ตราแกน แตกแกน ลมหายใจเวท) ให้ตัวละครพูดแบบคุ้นเคย เหมือนเราพูดคำว่า "แบตหมด" โดยไม่ต้องอธิบาย

## คำหยาบ (มีได้ แต่จำกัด)

### ระดับ
| ระดับ | ตัวอย่าง | ใช้เมื่อ |
|---|---|---|
| 1 เบา | กู มึง เอ็ง ข้า · ไอ้บ้า · โว้ย · เวร | คุยกันปกติในหมู่เพื่อนสนิท |
| 2 กลาง | แม่ง · เชี่ย · ห่า | ตกใจ โมโห เจ็บ |
| 3 แรง | เหี้ย · สัส | **ฉากพีคเท่านั้น** |

### โควตา
- ระดับ 2: ไม่เกิน **3 ครั้งต่อตอน** รวมทุกตัวละคร
- ระดับ 3: ไม่เกิน **2 ครั้งตลอดทั้งเรื่อง** ใช้เฉพาะจุดที่อารมณ์แตกจริงๆ
- ระดับ 2 ใช้ได้แค่ **มิโอกับเซ็ตสึ** (และพี่คาเนลตอนลับหลังคน)
- เรตเป้าหมาย: **13+**
- ห้ามด่าเพศ ด่าพ่อแม่ ด่าความพิการ หรือเหยียดคน (ยกเว้นตัวร้ายในฉากที่ต้องการให้คนดูเกลียด และต้องมีผลตามมาในเรื่อง)

### ใครพูดได้แค่ไหน
| ตัวละคร | ระดับสูงสุด | สไตล์ |
|---|---|---|
| มิโอ | 2 | เอ็ง/ข้า · "แม่ง" ตอนเจ็บ |
| เซ็ตสึ | 2 | กู/มึง กับเรน · "เชี่ย" หลุดตอนตกใจ |
| เรน | 1 | สุภาพ ใช้ "ฉัน/นาย" หลุดหยาบแค่ครั้งเดียวในเรื่องจะมีน้ำหนักมาก |
| โอลี่ | 1 | ครับ/ผม กับผู้ใหญ่ · พอสนิทกับทีมใช้ "เรา/นาย" |
| ฮารุ | 0–1 | ไม่ด่า ถ้าด่าแปลว่าอารมณ์ทะลัก (น้ำจะไหลด้วย) |
| พี่คาเนล | 0 ต่อหน้าคน · 2 ลับหลัง | หยาบเฉพาะตอนไม่มีกล้อง |
| เจ้าหน้าที่กรมฯ | 0 | สุภาพตลอด ความน่ากลัวอยู่ตรงนั้น |

### เทคนิค
- **คำหยาบต้องบอกนิสัย** ไม่ใช่ใส่ให้ดูเท่
- คนที่ไม่เคยด่าแล้วด่า = จุดพีค ใช้ได้ครั้งเดียว
- ถ้าบอลลูนนั้นตัดคำหยาบออกแล้วยังได้อารมณ์เท่าเดิม ให้ตัด
